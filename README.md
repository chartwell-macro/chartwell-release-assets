# Chartwell catalogue release assets

Immutable discovery catalogues used by Chartwell. Release asset hashes and their original source attribution are retained in `catalogues.json` and each release note. These files contain discovery metadata; they do not grant rights beyond the upstream terms.

- BLS: https://download.bls.gov/pub/time.series/
- ILOSTAT: https://ilostat.ilo.org/
- IMF World Economic Outlook: https://www.imf.org/en/Publications/WEO ; https://www.imf.org/en/About/copyright-and-terms . IMF conditions remain applicable, including noncommercial use restrictions carried by the Chartwell release.

No credentials or user Library data are included.
